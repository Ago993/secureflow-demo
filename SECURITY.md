# Security

SecureFlow is intentionally designed as an offline/local portfolio demo.

- No remote scanning.
- No credential collection.
- No background network calls.
- No external JavaScript or CSS.
- Imported files remain in the browser session and are not uploaded.
- Exported reports are created locally through the browser.

If this demo is adapted for real client work, every technical check against a live asset must have explicit authorization and a written scope.
